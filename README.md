# 小庆魔方（原音量魔方） · 桌面悬浮窗

一个显示 **声音输出设备** 与 **音量合成器(应用音量)** 的桌面悬浮窗。外观仿照天气小组件：**整块圆角面板 + 雨雾山景柔焦底图 + 半透明圆角磨砂卡片**，暖金色调 UI；音量合成器显示各程序的**真实软件图标**。可拖动、可缩放、可锁定位置、可桌面置底、可折叠；折叠态保留完整主音量卡片（图标 / 设备名 / 大号百分比 / 音量条），带流畅过渡动画。

## 启动

**方式一（推荐，免装 Python）**：双击 `小庆魔方.exe`（单文件，无控制台，图标/底图已内置，可直接拷给别人用）。

**方式二（改代码即生效）**：双击 `启动音量魔方.vbs`（无黑色控制台窗口，后台运行）。

或命令行：`python volume_floating.py`

> exe 为 onefile 打包，首次双击需解包到临时目录，启动会比源码方式慢几秒；改动 `volume_floating.py` 后需重新打包：双击 `打包exe.bat`（按 `volume_floating.spec` 生成，产物在 `dist\小庆魔方.exe`）。
> **开机自启动**：托盘图标右键（或窗口右键）→ 勾选「开机自启动」，见下一节。

## 开机自启动（菜单开关）

托盘图标右键或窗口右键 → 「开机自启动」，勾选即开启、取消勾选即关闭，即时生效，下次登录 Windows 自动运行。

- 写入 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`，值名 `XiaoQingMoFang`；只影响当前用户，**不需要管理员权限**。
- 路径自动取当前运行的 exe；**移动 exe 位置后，取消再重新勾选一次**刷新路径（旧路径不会再生效，菜单也会显示为未开启）。
- 状态以注册表为准，不写进 `~/.volume_cube_config.json`；托盘菜单切换成功后会弹气泡提示。
- ⚠️ 与在「启动」文件夹里放 `音量魔方.lnk` 快捷方式是**两种独立方式**，同时启用会开机打开两个实例。若以前手工放过快捷方式，请先删掉再勾选菜单。
- 源码方式（`启动音量魔方.vbs` / `python volume_floating.py`）运行时，写入的是 `pythonw.exe + 脚本路径`，不会弹黑色控制台。

## 背景样式（右键 → 背景样式，三选一，记住设置）

| 模式 | 效果 | 适用 |
| --- | --- | --- |
| 磨砂透明 `frost`（默认） | 启动时抓一张整屏快照 → 重度模糊 + 压暗成「整屏磨砂图」，绘制时按窗口位置裁一块贴上，看起来就是毛玻璃透桌面 | 摆在桌面上、置底当小组件 |
| 纯透明 `clear` | 完全不画底，桌面壁纸和后面的窗口原样透出来 | 想看清桌面/后面内容 |
| 照片 `photo` | 原来的雨雾山景底图（`bg_weather.jpg` 合成） | 不依赖桌面壁纸、换机器也一致 |

实现要点（踩过的坑，别再改回去）：

1. Win11（26200）上 WCA 亚克力 `SetWindowCompositionAttribute` 渲染出来是一层**不透明灰**，把 `GradientColor` 的 alpha 压到 2/255 也照样不透内容 —— 系统模糊这条路直接放弃；`DWMWA_SYSTEMBACKDROP_TYPE` 云母/亚克力同样是整块纯色，也放弃。
2. 早期版本按窗口坐标**每次移动/缩放都重算模糊**（解码 4096×2081 壁纸 66ms + 两次缩放），一旦和音频采样线程（pycaw 枚举 44 个端点约 570ms）撞上就会卡死。现在改为**整屏磨砂图只算一次**，绘制路径只有一次 `drawPixmap(target, pm, sourceRect)`，重绘实测平均 0.7ms / 最大 1.3ms，拖动缩放折叠零停顿。
3. 磨砂原料用 `QScreen.grabWindow(0)` 在**窗口显示之前**抓（切换模式时先 `hide()` 再抓再 `show()`），这样拍不到自己、没有递归变暗；也不用读注册表壁纸文件——用户用了「幻灯片/Windows 聚焦」时注册表指向的图和实际显示的不是同一张，颜色会对不上。
4. 代价：磨砂反映的是抓快照那一瞬间的桌面。桌面内容大改（换壁纸、开全屏游戏）后想更新，重开程序或在菜单里重新选一次「磨砂透明」即可。

## 换背景 / 换图标（外置优先，内置兜底）

exe 运行时按文件名找资源：**exe 同目录的 `bg_weather.jpg` / `app.ico` 优先**，找不到才用打包进去的内置副本（`_resource_file()` 逐个解析，两个文件互不影响）。

- 换背景：任意竖版图（建议 760×950 左右）改名成 `bg_weather.jpg` 放 exe 旁边，重启生效；删掉即回退内置雨雾山景。
- 换图标：任意多尺寸 `.ico` 改名成 `app.ico` 放 exe 旁边，重启生效（头像与托盘图标一起换）。

## 显示内容

- **默认输出设备**：大音量条 + 实时音量百分比 + 静音开关 + 均衡器动画
- **输出设备**：所有播放设备（含系统默认扬声器 Realtek），各自音量条与静音按钮，点名称切换默认设备（实心金色圆点为当前默认设备）
- **音量合成器**：每个正在发声的应用程序的独立音量，实时同步系统，并显示该程序的真实 exe 图标（按进程 PID 提取并缓存）

## 配置文件

位置与状态保存在 `~/.volume_cube_config.json`（pos / size / pinned / bottom / locked / collapsed），下次启动自动恢复。置顶、桌面置底、锁定、折叠均在右键菜单 / 标题栏按钮中切换。

## 资源

- `app.ico`：程序图标（窗口标题栏 / 左上角 logo / 系统托盘），替换此文件即可自定义图标。
- `bg_weather.jpg`：雨雾山景底图。启动时一次性做柔焦 + 提亮 + 轻微水珠细节的合成，之后每帧只做一次等比裁切贴图（不在绘制里创建图像，避免缩放/折叠时卡顿）；换成任意竖版照片即可换背景，删除该文件则回退为深蓝渐变底。
- 面板圆角由 `paintEvent` 里的抗锯齿路径绘制（半径 26），卡片圆角 18：半透明磨砂渐变 + 细描边 + 柔和投影，悬浮在照片上。
- 头像 / 程序图标为圆角方形（QPainterPath 裁剪）。
- 桌面置底通过 Win32 `SetWindowPos(HWND_BOTTOM)` 实现并去掉 `WS_EX_TOPMOST`，与置顶互斥。
